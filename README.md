# Instalación

## 1. Clonar repositorio

```bash
git clone https://github.com/Tejada90/rl-course_EIA_20262/tree/main
cd rl-course_EIA_20262
```

## 2. Abrir

```bash
code rl-course_EIA_20262
```

### Levantar Docker

```bash

```
