# Entrega del reto 01

Esta carpeta debe contener el notebook desarrollado por el estudiante y su exportación a HTML.

## Nombre del notebook

Utiliza:

```text
reto_01_apellido_nombre.ipynb
```

Ejemplo:

```text
reto_01_perez_ana.ipynb
```

No utilices:

- Espacios.
- Tildes.
- Eñes.
- Caracteres especiales.
- Nombres como `final.ipynb` o `entrega.ipynb`.

## Exportación

Guarda el HTML en:

```text
submission/exports/
```

Ejemplo:

```text
submission/exports/reto_01_perez_ana.html
```

## Estructura esperada

```text
submission/
├── README.md
├── reto_01_perez_ana.ipynb
└── exports/
    └── reto_01_perez_ana.html
```

## Antes de entregar

1. Abre el notebook.
2. Selecciona **Restart Kernel and Run All Cells**.
3. Verifica que no existan errores.
4. Guarda el notebook.
5. Exporta a HTML.
6. Ejecuta:

```bash
pytest
```

7. Revisa:

```bash
git status
```

8. Revisa los archivos que serán enviados.
9. Crea el commit.
10. Publica la rama.
11. Crea el Pull Request.
