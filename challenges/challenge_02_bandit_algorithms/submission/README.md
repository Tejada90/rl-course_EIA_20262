# Entrega del Reto 02

Esta carpeta debe contener únicamente el notebook desarrollado y su
exportación a HTML.

## Nombres esperados

```text
reto_02_apellido_nombre.ipynb
exports/reto_02_apellido_nombre.html
```

Ejemplo:

```text
reto_02_perez_ana.ipynb
exports/reto_02_perez_ana.html
```

No utilices espacios, tildes, eñes, mayúsculas ni nombres como `final.ipynb`.

## Antes de entregar

1. Ejecuta **Restart Kernel and Run All Cells**.
2. Confirma que todas las celdas terminen sin errores.
3. Revisa tablas, gráficas e interpretaciones.
4. Exporta el notebook a HTML.
5. Ejecuta `pytest -q`.
6. Agrega únicamente el notebook personal y su HTML.
7. Publica una rama `challenge-02-nombre-apellido`.
8. Crea un Pull Request hacia `main`.
